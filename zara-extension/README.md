# Маркетинг: пуши и баннеры — расширение

Боковая панель к рабочей таблице Зары (старый формат: «Заказы на перевод пушей/баннеров»).
Связь с таблицей — через отдельный скрипт-мост (`marketing-translations/zara-stats/Мост.gs`), код таблицы не меняется.

- 📋 **Запросы** — свежие строки заказчиков: заказанные языки зелёные (переведено) или красные (ждёт),
  «♻️ Проверить по архиву» подставляет готовые переводы в пустые заказанные языки; уведомления о новых строках.
- 🔎 **Архив** — вставьте текст: тот же / другие эмодзи / цифры / знаки / похоже, с переводами.
- 📊 **Статистика** — по умолчанию текущий месяц; прошлый, 3 месяца, всё время; «Полный отчёт» с выгрузкой в Google Таблицу.
- 📥 **Файлы** — xliff от подрядчика → в строки заказчиков, только в заказанные языки и пустые ячейки.

`jszip.min.js` — JSZip 3.10.1 (MIT, `LICENSE-jszip.md`).
