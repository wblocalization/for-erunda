# Переводы маркетинга — новая таблица

Таблица запросов на перевод: пуши — на вкладке «📥 Пуши», баннеры — на «🖼 Баннеры». Маркетологи пишут новый запрос
в первую пустую строку внизу.
Работает без расширения — через меню «🌍 Переводы».

Как читать таблицу: ✍️ розовые заголовки заполняет заказчик, 🤖 серые заполняются сами, цветные KK, UZ… — переводы.
У каждого заголовка вторая строка — подсказка. Статусы с иконками: 🆕 Новый, ♻️ Из архива, ⚠️ Проверить, 📤 У подрядчика,
✅ Готово, 📨 Отдан, ✖️ Отменён. Легенда — на вкладке «📖 Как заполнять» и в меню
«🌍 Переводы → 📖 Что значат цвета и статусы».

- `Код.gs` — скрипт таблицы: ID, дата и статус; поиск в архиве и подстановка готовых переводов
  (тот же текст / другой эмодзи — зелёным, другие цифры или знаки — жёлтым, похожий на 90% — подсказка);
  проверка лимита символов; архив; статистика; API для расширения (`doGet` / `doPost` с ключом).
- `Smartcat.html` — окно «Загрузить переводы от подрядчика»: файлы .xliff (их выгружает Smartcat подрядчика), по одному, несколько или zip,
  предпросмотр, вставка в нужные строки и языки.
- `migrate.py` — перенос старой таблицы в новую: `python3 migrate.py старая.xlsx новая.xlsx`.

Данных в репозитории нет: таблица с текстами живёт только в Google.

## Установка

1. Загрузить новую таблицу на Google Диск и открыть как Google Таблицу.
2. Расширения → Apps Script: вставить `Код.gs`; «+» → HTML → `Smartcat`, вставить `Smartcat.html`; сохранить.
3. Обновить таблицу → «🌍 Переводы» → «⚙️ Настроить таблицу» (запускает тот, кто ведёт таблицу) → разрешить доступ.
   Таблицу, созданную прошлой версией, эта же команда переоформит: подсказки в заголовках, статусы с иконками, цвета.
4. Если стоит расширение: после обновления `Код.gs` — «Развернуть» → «Управление развёртываниями» → ✏️ → версия «Новая» → «Развернуть»
   (ссылка `…/exec` останется прежней).
