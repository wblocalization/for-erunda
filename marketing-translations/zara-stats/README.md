# 📊 Статистика для таблицы Зары

Отчёт по запросам на перевод прямо из рабочей таблицы (старый формат: «Заказы на перевод пушей/баннеров»).
Таблица **не меняется**: скрипт только читает листы.

- `Статистика.gs` — считает: запросы по месяцам, языки, продукты, типы баннеров, повторы
  (тот же текст / другие эмодзи / знаки / цифры / похоже на 90%+, только за более ранние дни), ставку за слово по «Анализу переводов».
- `StatsReport.html` — страница отчёта: период (по умолчанию текущий месяц), выгрузка в новую Google Таблицу.
- `ZsUpload.html` — окно «📥 Загрузить переводы от подрядчика (xliff)»: переводы встают в строки заказчиков, только в заказанные языки и пустые ячейки.
- Подстановка из архива: когда в пушах или баннерах вписывают текст RU, пустые ячейки нужных языков заполняются переводом из архива (зелёные — тот же текст или эмодзи, жёлтые — цифры или знаки), заметка — откуда. Заполненное не трогается.

## Установка
1. В таблице: Расширения → Apps Script → «+» → Скрипт → «Статистика» → вставить `Статистика.gs`.
2. «+» → HTML → `StatsReport` → вставить `StatsReport.html`; «+» → HTML → `ZsUpload` → вставить `ZsUpload.html`. Сохранить.
3. Выбрать функцию `zsSetup` → «Выполнить» → разрешить доступ.
4. Обновить таблицу → меню «📊 Статистика → Открыть отчёт».

Безопасность: нет `onOpen` и `doGet`, все имена с приставкой `zs` — существующий скрипт таблицы не задевается.
Меню ставится отдельным триггером открытия. Результат кэшируется на 20 минут («Пересчитать заново» — сразу).

## Расширение «Переводы Зары» (по желанию)
Расширению нужен адрес веб-приложения, а `doGet` в таблице Зары уже занят её загрузкой файлов.
Поэтому для расширения — отдельный проект-«мост» на Google Диске (не внутри таблицы):
1. script.google.com → «Новый проект» → файлы «Статистика» (`Статистика.gs`), «Мост» (`Мост.gs`), HTML «StatsReport».
2. В `Мост.gs` вписать ссылку на таблицу в `ZS_TABLE_URL` → 💾 → выполнить `zsBridgeSetup` → в журнале выполнения будет ключ.
3. «Развернуть» → «Новое развёртывание» → «Веб-приложение», от моего имени, доступ «Все» → ссылка …/exec.
4. Расширение `zara-extension`: ⚙ → ссылка и ключ.
