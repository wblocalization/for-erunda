# Ягодка — рабочий браузер

Свой браузер на Chromium (Electron) для рабочих задач. Главное отличие от обычного: **свои расширения запускаются прямо из папки**,
без магазина Chrome и без политик, которые запрещают установку.

Что есть:
- **Сервисы слева** — почта, Band, Tracker, Wiki, Smartcat, таблицы. Остаются открытыми, переключение по клику или `Alt+1…9`.
- **Вторая панель рядом** — любой сервис, вкладку или панель расширения можно открыть справа от текущей страницы
  (`Ctrl+клик` по значку, «Открыть рядом» по правой кнопке, `Ctrl+\`). Ширина меняется перетаскиванием.
- **Расширения** — уже встроены «Рестайл почты» (`owa-restyle`), «Рестайл Band» (`band-restyle`), «Задачи и сметы»
  (`smeta-extension`) и «Weblate ⇄ Smartcat» (`weblate-extension`). Другие добавляются в «Настройки → Расширения → Добавить из папки».
- **Быстрый переход** `Ctrl+K` — поиск по сервисам, вкладкам, закладкам и истории.
- **Перевод выделенного** — правая кнопка по выделенному тексту открывает переводчик рядом; список настраивается.
- **Оформление** — пять цветовых тем, светлый и тёмный режим, анимации (отключаются в «Настройки → Общее»).
- **Перенос из Chrome** — «Настройки → Перенос»: закладки, история и куки (входы на сайты) из Chrome, Edge, Яндекс.Браузера
  и других браузеров на Chromium. Куки расшифровываются ключом Windows, поэтому работают только на том же компьютере, где стоит
  браузер-источник, и его нужно закрыть на время переноса. Очень свежие версии Chrome шифруют куки по-новому — такие могут не перенестись.
- **Пароли** — при входе на сайт браузер предлагает сохранить пароль и потом подставляет его сам. Хранятся только на этом
  компьютере, зашифрованы средствами Windows (DPAPI); список — в «Настройки → Пароли».
- Обычное: вкладки, закладки, поиск по странице, масштаб, печать, проверка орфографии, восстановление вкладок после перезапуска.

## Запуск на Windows

Готовая сборка: распаковать `Yagodka-…-win.zip` в любую папку и запустить `Yagodka.exe`. Установка и права администратора не нужны.
Файл не подписан, поэтому Windows при первом запуске может показать предупреждение SmartScreen («Подробнее → Выполнить в любом случае»).

Из исходников (нужен Node.js 20+):

```
cd work-browser
npm install
npm start
```

Собрать архив самостоятельно: `npm run dist` — результат в `dist/`.

Данные (вкладки, закладки, входы на сайты, настройки расширений) лежат в `%APPDATA%\Yagodka` и никуда не отправляются.

## Как устроены расширения

Electron не умеет магазин Chrome и поддерживает расширения лишь частично, поэтому у «Ягодки» свой небольшой движок (`src/extensions.js`):

| Возможность расширения | Как работает |
|---|---|
| `content_scripts` (в том числе `world: MAIN`, `run_at`) | Скрипты внедряются в подходящие страницы в отдельном изолированном мире |
| Страницы расширения: `side_panel`, `action.default_popup`, `options_page` | Открываются во второй панели или во вкладке по адресу `locext://имя-папки/…` |
| `background.service_worker` | Работает в скрытой странице, пока открыт браузер |
| `chrome.storage.local / sync / session`, `onChanged` | Файл в профиле браузера (`sync` между устройствами не синхронизируется) |
| `chrome.runtime` — `getURL`, `sendMessage`, `onMessage`, `openOptionsPage`, `onInstalled` | Да |
| `chrome.action` — значок с числом, подсказка | Значок расширения в левой колонке |
| `chrome.sidePanel.open`, `chrome.notifications`, `chrome.alarms` | Да (кнопка уведомления показывается в строке под адресом) |
| `chrome.tabs` — `query`, `get`, `create`, `update`, `remove`, `onUpdated`, `onRemoved` | Да; сервисы из левой колонки тоже считаются вкладками |
| `chrome.scripting.executeScript` — `files` и `func`, миры `ISOLATED` и `MAIN` | Да, на сайтах из `host_permissions` или после клика по значку (`activeTab`) |
| `chrome.offscreen`, `chrome.runtime.getContexts` | Невидимая страница, например для звука |
| `chrome.action.onClicked` | Клик по значку расширения в левой колонке |
| `fetch` к сайтам из `host_permissions` | Идёт без проверки источника, как в Chrome |

Остальные API (`webRequest`, `contextMenus`, `declarativeNetRequest`, `cookies` и т. д.) не поддерживаются: расширение из магазина,
которому они нужны, может не заработать. Свои расширения проще дописать под этот список.

Какие расширения попадают в сборку, задаёт список `build.extraResources` в `package.json`; при запуске из исходников берутся они же из соседних папок.

Идентификатор расширения — имя его папки. После правки файлов расширения: «Настройки → Расширения → Перезапустить расширения».

## Проверка

```
xvfb-run -a npm test        # Linux; на Windows просто npm test
```

Сценарий `test/run.js` запускает браузер с заглушками вместо рабочих сайтов и проверяет вкладки, сервисы, расширения,
вторую панель, быстрый переход и сохранение сессии.

## Что важно знать

- На рабочем компьютере действуют правила компании. Браузер, собранный самостоятельно, ИТ-отдел не проверял и не обновляет —
  стоит хотя бы предупредить руководителя, а обновлять сборку (новую версию Electron) придётся самим.
- Вход в Google внутри Electron иногда блокируется самим Google («браузер может быть небезопасен»).
- Корпоративный вход по сертификату или привязке к устройству может не сработать в стороннем браузере.
