# Термбаза — сайт-глоссарий

**Открыть демо:** скачайте `index.html` (кнопка «Download raw file» на странице файла) и откройте в браузере.
Пароль — у команды локализации. Термины в демо выдуманные, переводы примерные.

Что есть на сайте:
- вход по паролю: без пароля термины прочитать нельзя, на странице они зашифрованы (AES-256, ключ из пароля);
- поиск сразу по RU, EN и всем языкам;
- вкладки «Все языки» и по каждому языку (KA, HY, KK, KY, TR, TG, UZ, ZH) с прогрессом перевода и фильтром «Без перевода».
  У каждой вкладки своя ссылка: `index.html#/KA`;
- варианты перевода с пометкой, когда их использовать; копирование в один клик; ссылка на термин по клику на ID;
- «Как это работает?»: откуда берутся термины, где их править и как часто обновляется сайт.

## Как устроено

1. **Termbase** — русские и английские термины, утверждает английская команда.
2. **Таблица на все языки** — переводы; туда термины проливаются из Termbase.
3. **Сайт** — только для поиска и просмотра. Раз в час GitHub забирает термины из таблицы на все языки
   (код `apps-script/site-data.gs`), шифрует паролем и обновляет страницу. Править на сайте нельзя:
   кнопка «поправить в таблице» под термином открывает его строку в таблице.

## Файлы

- `index.html` — готовый сайт с демо-терминами.
- `template.html` — сайт без данных; `build.js` шифрует данные паролем и собирает `index.html`:
  `node build.js <пароль> demo-data.json index.html`.
- `demo-data.json` — демо-термины.
- `apps-script/site-data.gs` — код для таблицы на все языки: отдаёт термины сайту по секретному ключу.
- `github-workflow-site.yml` — автообновление раз в час для отдельного репозитория с GitHub Pages
  (положить в `.github/workflows/`). Секреты: `SITE_PASSWORD`, `TERMBASE_URL`, `TERMBASE_TOKEN`.
