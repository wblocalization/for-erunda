# Переводы маркетинга — расширение

Пульт к таблице «Переводы маркетинга» в браузере (Chrome, Яндекс Браузер). Таблица работает и без него.

- 🔔 уведомление о новом запросе и цифра на значке;
- окошко по вкладкам: новые, из архива, у подрядчика, готово;
- у каждого запроса — что уже переводили и чем текст отличается (эмодзи, цифры, знаки);
- кнопки: проверить по архиву, «У подрядчика», «Готово», «Отдан», скопировать переводы для треда, открыть строку в таблице;
- 📥 zip из Smartcat (в том числе zip в zip) → предпросмотр → переводы встают в нужные строки и языки.

## Подключение

1. В таблице: Расширения → Apps Script → «Начать развёртывание» → «Новое развёртывание» → тип «Веб-приложение»,
   «Запуск от имени: от моего имени», «У кого есть доступ: Все» → скопировать ссылку `…/exec`.
2. В таблице: меню «🌍 Переводы» → «🔑 Ключ для расширения» → скопировать ключ.
3. Установить расширение: `browser://extensions` или `chrome://extensions` → «Режим разработчика» →
   «Загрузить распакованное расширение» → папка `loc-requests-extension`.
4. Нажать на значок → ⚙ → вставить ссылку и ключ → «Сохранить и проверить».

Без ключа таблица ничего не отдаёт. Данные ходят только между браузером и вашей таблицей.
