# Переводы маркетинга — расширение

Пульт к таблице «Переводы маркетинга» в браузере (Chrome, Яндекс Браузер). Таблица работает и без него.

Открывается **боковой панелью** справа (клик по значку). Где браузер не умеет боковые панели — обычным окошком.

- 📋 **Запросы** — плитки по статусам (🆕 Новые, ♻️ Из архива, ⚠️ Проверить, 📤 У подрядчика, ✅ Готово), поиск, фильтр пуши / баннеры;
  в карточке — что уже переводили, дедлайн (просрочен / скоро), переводы (клик — скопировать язык), кнопка следующего шага;
  массово: «проверить все по архиву», «отметить все как Отдан».
- 🔎 **Архив** — вставьте текст: найдёт такой же или почти такой же (эмодзи, цифры, знаки) и тексты с теми же словами, с переводами.
- 📊 **Статистика** — за месяц, в работе, взято из архива, просрочено; запросы по месяцам, языки, продукты, типы баннеров.
- 📥 **Файлы** — переводы от подрядчика: файлы .xliff (из его Smartcat), по одному, несколько сразу или zip → предпросмотр → переводы встают в нужные строки и языки.
- 🔔 уведомление о новом запросе и цифра на значке.

## Подключение

1. В таблице: Расширения → Apps Script → «Начать развёртывание» → «Новое развёртывание» → тип «Веб-приложение»,
   «Запуск от имени: от моего имени», «У кого есть доступ: Все» → скопировать ссылку `…/exec`.
2. В таблице: меню «🌍 Переводы» → «🔑 Ключ для расширения» → скопировать ключ.
3. Установить расширение: `browser://extensions` или `chrome://extensions` → «Режим разработчика» →
   «Загрузить распакованное расширение» → папка `loc-requests-extension`.
4. Нажать на значок → откроется панель → ⚙ → вставить ссылку и ключ → «Сохранить и проверить».
   Обновляете расширение — там же на `chrome://extensions` нажать ⟳ у расширения.

Без ключа таблица ничего не отдаёт. Данные ходят только между браузером и вашей таблицей.
