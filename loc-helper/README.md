# Loc Helper

Расширение для Chrome (и Яндекс Браузера) для менеджеров локализации. Связывает Band (`https://band.wb.ru`) и
Tracker (`https://tracker.wb.ru`) через WB Tracker Public API и ваш личный API-токен.

## Что умеет

- **Задача из брифа.** В Band при наведении на сообщение появляется кнопка «→ Tracker». Она открывает форму,
  уже заполненную из брифа: название, языки, дедлайн, описание со ссылкой на тред и именем заказчика.
  Если заказчик прислал исправленный бриф в треде, берётся последний. Форму можно поправить или закрыть.
- **Куда отправить.** Новая задача, подзадача в выбранный тикет (например, еженедельный «Переводы WBP XS»)
  или комментарий в существующий тикет. Тикет выбирается из своих открытых задач или по номеру; последний выбор запоминается.
- **Поля Tracker.** Форма показывает поля-списки типа задачи: «Приоритет», «Бизнес-заказчик», «Формат», «Страны»,
  а также дедлайн, дату начала и завершения. По брифу подставляется только сказанное прямо: страны по названным языкам,
  формат по словам «пуш», «баннер» и т. п., заказчик при точном совпадении с продуктом. Такие поля помечены «проверьте».
- **Исполнитель** по умолчанию — тот, кто нажал кнопку (выбирается в настройках, «Кто я»).
- **Подзадачи.** На каждый выбранный язык, по желанию отдельно на перевод и на редактуру.
  В открытой задаче Tracker есть кнопка «Подзадачи по языкам»: копии с тем же описанием и полями.
- **Свободный текст.** Если бриф написан не по шаблону, языки, срок и ссылки ищутся по всему сообщению,
  приветствия и благодарности убираются. Всё после строки «Текст:» не меняется.
- **Ответ в тред.** После создания расширение пишет в тред ссылку на задачу и ставит ✅ на бриф (можно отключить).
- **Чего не хватает.** Форма показывает, чего нет в брифе (это подсказка, а не запрет), и даёт скопировать ответ заказчику.
  После создания видно, какие поля задачи остались пустыми.
- **Подсветка дедлайнов в Tracker.** Красная рамка у просроченных карточек, жёлтая у задач на сегодня, рядом с номером — срок.
- **Список дедлайнов.** В окошке расширения задачи разложены на «Просрочено», «Сегодня», «Завтра», «Позже»;
  на значке — число горящих задач.
- **Напоминания.** Колокольчик у задачи включает уведомления браузера за 24 и 3 часа до дедлайна (часы настраиваются).
  По умолчанию выключены.

## Установка

1. Распакуйте архив — получится папка `loc-helper`. Положите её куда-нибудь насовсем.
2. Откройте страницу расширений: `browser://extensions` (Яндекс Браузер) или `chrome://extensions` (Chrome).
3. Включите **Режим разработчика** и нажмите **Загрузить распакованное расширение** → выберите папку `loc-helper`.
4. Нажмите на значок расширения → **Настройки**. Вставьте API-токен из профиля Tracker и номер любой задачи
   локализации (например, `LOCAL-2210`), нажмите **Подключить**.
5. Выберите себя в списке «Кто я» и обновите открытые вкладки Band и Tracker.

## Ограничения

- Напоминания приходят, только пока открыт браузер: расширение само опрашивает Tracker раз в 10 минут.
- Напоминания видит только тот, у кого стоит расширение. Чтобы они приходили всем в Band, нужен отдельный бот.
- Бриф разбирается по строкам вида `Языки: …`, `Сроки: …`, `Продукт: …`, `Контекст: …`, `Визуал: …`, `Текст: …`.
  Свободный текст без таких строк попадёт в описание целиком, а поля формы придётся заполнить руками.
- Типы задач и список людей собираются из существующих задач проекта: у API нет отдельных списков.
- Поля «Reviewer» и «SP» в форму не выводятся: их заполняет исполнитель по ходу работы.
- Вложения из треда в задачу не копируются, в описании остаётся ссылка на тред.
- Отдельного поля «Язык» в Tracker нет: языки идут в описание, названия подзадач и поле «Страны».

## Токен

Токен хранится в хранилище расширения в этом браузере и отправляется только на `tracker.wb.ru`.
Страницам сайтов доступ к нему закрыт. Кнопка «Отключить и стереть токен» в настройках удаляет его вместе со списком задач.

## Если что-то не работает

- **«Tracker не принял токен».** Формат личного токена в документации не описан, расширение перебирает варианты.
  Если ни один не подошёл, заполните в настройках поле «Логин» (ваш логин в Tracker) и попробуйте ещё раз.
- **Кнопка «→ Tracker» перекрывает меню Band или не появляется** — пришлите скриншот.
- **Нет подсветки в Tracker.** Расширение ищет номера задач по названиям классов на странице. После обновления
  трекера они могут поменяться: сохраните страницу (Ctrl+S, «Веб-страница полностью») и пришлите её.
- **Ссылки на задачи ведут не туда.** Откройте любую задачу в Tracker — расширение запомнит вид ссылки.
  Или поправьте поле «Ссылка на задачу» в настройках.

## Файлы

- `manifest.json` — описание расширения.
- `background.js` — фоновый скрипт: запросы к Tracker, опрос раз в 10 минут, уведомления, счётчик.
- `lib/core.js` — работа с API Tracker: подключение, список задач, создание, подзадачи, напоминания.
- `lib/brief.js` — разбор брифа и дат.
- `lib/ui.js` — окно формы и выбор языков для страниц.
- `band.js` — кнопка и форма в Band.
- `tracker.js` — подсветка и кнопка «Подзадачи по языкам» в Tracker.
- `popup.html`, `popup.js` — окошко со списком дедлайнов.
- `options.html`, `options.js` — настройки.
- `page.css` — стили окошка и настроек.
